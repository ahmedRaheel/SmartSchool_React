# SmartSchool mock lifecycle v4
Generic web modules now use one app-level in-memory store. Records support create, search/filter, open, edit, save, reopen and delete. Changes survive route navigation during the current app session and intentionally reset on browser refresh.

Notifications and chat now open as right-side slide-over panels. Notification read/unread state is interactive. Chat supports conversation selection, in-memory sent messages, Enter-to-send and navigation to the related module.

# SmartSchool React v99

- Dedicated Admissions workspace; no direct Add Student from Student Directory.
- Admission statuses: Submitted Application, Admission Accepted, Admission Rejected, Waiting List.
- Admission criteria management is visible in Admissions.
- HR add form has staff category (Teacher, Driver, Principal, Admin Officer and other non-teaching staff), contact/emergency details and photograph upload; no user-selectable initial status.
- Recruitment status dropdown drives Hired/Rejected/Waiting List. Hired provisions account through backend approval.
- Academic Operations exposes explicit Academic Years, Classes, Subjects, Courses, Teacher Assignments, Timetables and Timetable Entries sections.
- Organization supports update/delete, loader, and Country -> Province -> City selector.
- Document Management has a real upload workflow and Student/Employee record selection.
- Added global API loader driven by Axios request count.
